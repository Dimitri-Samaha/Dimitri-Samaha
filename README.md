# Hi, I'm Dimitri

Most of the repositories on this profile are programming projects I wrote in high school, all from 2023 and before. I'm keeping them public as an archive of how I learned to code, so please read them in that spirit rather than as current work.

This account is not the one these projects were originally published under; I lost access to my old account, so everything has been moved here.

The collection is a mix of personal projects I built for fun, academic work done for school, and a few things I never finished. Some repositories blend more than one of those at once.

## Internship
During terminale (the final year of French high school), I interned at Siren Analytics. There I developed and optimized Angular components for FENIX, a project delivered for a Lebanese public administration, which improved the application's performance and user experience. I also researched reusable components meant to be shared across multiple internal projects.

A recommendation letter from this internship is available if needed; feel free to reach out.

## Personal projects
These were built on my own time, out of curiosity rather than an assignment.
- `pygame-chess`: a chess game with an AI opponent powered by Stockfish.
- `pygame-snake`: a classic Snake game.
- `pygame-ping-pong`: a Pong clone with a menu and an AI opponent.
- `pygame-real-physics`: a small orbital gravity sandbox.
- `pygame-obstacle-dodger`: a simple arcade dodging game.
- `console-game-hub`: a terminal launcher bundling several small games.
- `face-position-game`: a webcam game that tracks your face position with OpenCV.
- `password-manager`: a simple local password vault, built as a learning exercise.
- `tachycardia-tracker`: a personal command line symptom diary.
- `expense-tracker`, `note-taker`, `to-do-list`: small vanilla JavaScript, HTML, and CSS apps.
- `goal-setter`: a Django app for tracking personal goals.
- `django-website-01`: a Django site bundling a login system with a few small browser games.
- `personal-site`: the backend of an old personal portfolio site.

## Academic work
These came out of school, either lycée (French high school) or an introductory programming course.
- `lycee-homework`: French high school math and programming homework.
- `random-projects`: beginner exercises from an intro programming course.
- `tkinter-widget-demos`: a set of demo scripts written while learning the Tkinter GUI toolkit.
- `image-experiments`: small OpenCV experiments made while learning computer vision basics.
- `python-misc-scripts`: a couple of standalone practice scripts.

## Unfinished
Some things never got past the prototype stage, and I'm leaving them as they are rather than pretending otherwise.
- `pygame-watermelon-game`: a Suika style fruit merging game where the drop and collision detection work, but the actual merge logic was never completed.
- `django-website-01`: its speed test feature has routes and templates in place, but the timing logic itself was never wired up.

If something here looks rough, it probably is; I was a student learning as I went, not shipping production software.
